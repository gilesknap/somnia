## The fix, in one paragraph

Nothing told the model where the listener was, so the newest claim about their
position was the agent's own `"You're at chapter 2"` from a previous turn.
Asked again, it agreed with itself and moved nothing. Two earlier commits put
the position on the **end of the system prompt** and neither worked, for a
structural reason rather than a wording one: **the system prompt is read before
the whole conversation, so a stale sentence inside the conversation is the newer
statement.** The position now rides on the **head of every turn's question**,
where nothing can be newer than it, and is stripped back off before the question
is stored so the history does not accumulate positions that have all since been
wrong.

A second bug surfaced while testing it: a one-row list was told to say "There
are a few places that could be it", which is false about one place, so the model
improvised — and what it improvised was *"You're there now, at the beginning of
chapter 5"* over a book that had not moved. One row now has its own sentence.

## Loose ends

### 1. `measure-the-agent/evaluate.py` is broken

It calls `lib.heard_to_ms()`, which no longer exists — the skill's harness dies
on import. Two lines:

```python
HEARD_MS = lib.position_ms(GID)                    # was lib.heard_to_ms(GID)
from somnia.format import format_timestamp         # was from somnia.tools
```

I patched a copy on the box to get tonight's numbers; **the repo file is still
broken.**

### 2. The three-scenario probe is not in the repo

It is what turned "feels tighter" into 15/15, and it covers ground
`evaluate.py` does not: **a multi-turn conversation with a page seek in the
middle**, which is the only shape that reproduces #116. `evaluate.py` builds a
fresh `Conversation` per question and so can never see it.

A copy is at `.claude/handoffs/probe-2026-08-10.py`. It wants folding into the
`measure-the-agent` skill properly — and note it resets book positions between
reps, which the first version did not, and that alone produced one bogus
"failure".

### 3. Retrieval, still open and still unfiled

`find_passage` returns its five nearest however poor they are. The model now
prunes them, and that works (5/5 on both the one-hit and four-hit cases), but it
is judgement rather than mechanism and it varies with what the model chooses to
search for. A reranker or a better embedder is the real answer. **Not filed as
an issue.**

### 4. Prompt size

The system prompt is down 36% (866 → 542 words) and `offer_positions`' 
description is less than half what it was. **The tool docstrings are now the
bigger half of what is sent**: 4159 characters against the prompt's 2956, with
`recall` (907) and `find_passage` (851) the next candidates. They carry routing
and spoiler guidance, so trim them against the eval, not by eye.

## Traps worth carrying

- **The desk suite cannot see any of these failures.** 450 tests pass over every
  bug fixed tonight, because they drive the tools directly and so can never
  produce a turn in which the model declined to call one. Verify on the box.
- **A fresh token per turn hides #116.** Reuse one token across both turns or
  the bug will not reproduce.
- **Use Dracula (45839) for chapter tests**, not Frankenstein (41445) — it opens
  with letters, so somnia's chapter 2 is "LETTER II". That confounded a whole
  round of testing on a previous session.
- **The dogs in Black Beauty are in chapter 2, "The Hunt"** — 4:04, 4:39, 5:24,
  5:56 — not chapter 1. `chapter_idx` is 1; the chapter is 2.
- **`gh pr edit --base` fails** with a Projects-classic GraphQL deprecation
  error and silently does not retarget. Use
  `gh api -X PATCH repos/gilesknap/somnia/pulls/N -f base=main`.
- **`git commit` needs `--no-verify`** in this checkout: pre-commit's
  `web-tests` hook runs bare `node --test` and recurses into prunable worktrees
  under `.claude/worktrees/`. Run `node --test tests/web/` by hand instead. A
  `git worktree prune` would probably fix it — Giles's call.
- **`~/.ssh` is a symlink to `/cache/ssh` and a rebuild wipes it.** Relink
  rather than making a new key: `ln -s /cache/ssh /root/.ssh`.
